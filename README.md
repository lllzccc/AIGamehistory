# 女性向游戏编年史

中国女性向、宫廷与官斗游戏公司的发展、产品及公开人才资料。基于 Astro 的静态交互网站。

公开站点：https://lllzccc.github.io/AIGamehistory/

## 本地开发

使用 Node.js 22.12 或更新版本，运行 npm ci 和 npm run dev。

## 发布

推送 master 后自动执行测试、类型检查与构建，发布至 GitHub Pages。

资料来自公开来源，历史署名不代表当前任职。产品截图与商标权利属于各自权利人，首页群像为 AI 生成原创示意图。

收录指南：docs/superpowers/guides/how-to-add-a-company.md
