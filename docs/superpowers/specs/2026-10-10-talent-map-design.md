# 公司页人才地图

日期：2026-10-10
状态：已通过口头确认
父规格：`docs/superpowers/specs/2026-10-09-people-credits-design.md`

## 1. 目标

公司页「关键人物」下面增加「人才地图」：按项目列出历任关键角色，方便定向挖猎。LinkedIn / 脉脉本期只预留字段，不接抓取。

## 2. 两块分工

- **关键人物**：只放最高层。`scope: company`（创始人、董事长、CEO、总裁）。不再列制作人。
- **人才地图**：只放挂了产品的人。`scope: product`。按项目分组，组内按岗位再按任期。

某人同时是总裁又是某作制作人：上面出管理层履历，下面出项目署名。没挂产品的人不进地图。某个产品没有任何署名，这一栏不出现。整张地图为空则整节不出现。

## 3. 数据

人档增加可空外链：`linkedin`、`maimai`、`weibo`（均为 URL）。没有就不写。

岗位枚举增加 `core-designer`（核心策划）、`core-artist`（核心美术）。仍不收普通策划、原画、运营、CV、全员表。脉脉不当本期事实来源。

一行不另建表：继续从 `people[].roles` 派生。

## 4. 派生与界面

`getCompanyTalentMap(ds, companyId)`：该公司研发或发行的产品，各带 `getProductCredits`，只留 `role.company` 等于本公司的署名（代理发行不要把研发方主创算进来），丢掉空栏，产品按首发排。

每个项目一张表：岗位、姓名（链到 `/person/<id>`）、任期、状态（无 `to` = 在职，有 `to` = 离职）、来源。

个人页有外链才显示。

## 5. 本期不做

不画组织架构树。不接 LinkedIn / 脉脉。不批量新挖主创；已有产品署名（小萌、富永）迁进地图即可。查得到的公开制作人可顺手补一条，查不到留空。
