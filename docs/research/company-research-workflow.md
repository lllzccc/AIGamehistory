# 按公司深挖的收录流程
框架完成后，按叠纸 → 友谊时光 → 乐元素 → 灵犀推进；每家完成记录再换下一家。
“挖干净”指公开来源已逐项检查，未找到的项目记录缺口，不代表私人信息或全部员工已收全。

每家公司记录：
- 官网产品和历程：列出所有重点女性向产品，标收录、待核实、排除原因。
- 每个项目：制作人、执行制作人、主策、核心策划、主美、核心美术、编剧、音乐，逐岗记录公开署名或“未找到”。
- 每段履历：独立 sources；status 为 active/departed/unknown。active 必须有 checkedAt 和支持在任的来源。
- dateBasis：employment 为真实任职起点，public-observation 为公开亮相日期，unknown 为沿用待核日期。
- checkedAt 只在实际核对原文后填，旧资料迁移不自动写今天。
- 流动：项目调动与离开公司分别核实，不把结束项目当成公司离职；去向无来源留空。
- 来源不支持时撤回断言；百科和媒体是线索，优先官方、采访、署名。
- 搜索过的关键词、来源链接、仍未找到的岗位写入研究日志，避免自动化重复检索。
- 不采集私人联系方式，不发送招聘联系。
- 完成 npm test、npm run check、npx astro build 后形成公司完成报告。
