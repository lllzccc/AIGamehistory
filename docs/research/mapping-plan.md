# 公司 Mapping 计划与进度

入口：本地 http://127.0.0.1:4321/mapping/ ，网站顶部“研究进度”。默认显示 SLG，可切换女性向、休闲或全部公司。

## 如何阅读

- 多轮深挖：已多轮补充，**不等于已穷尽或验收**。
- 首轮/专题建档：已有代表产品与部分证据，待扩展公司范围。
- 仅列名：只有主体/产品线索，不计作正式产品档案。
- 范围已验收：五方向均核查，并有两个不同渠道连续两轮补检无关键新增；新资料仍可继续补。

截至2026-10-13，多轮补充重点为易娱、莉莉丝、江娱、IGG、FunPlus、点点与乐狗；目前没有一家达到完整范围验收标准。

进度页面自动读取公司五方向清单、产品和公开人员档案，显示实际建档数量、日期、已查范围和缺口。公司级清单跨卷共用，产品/人员数量随卷筛选；不会把转载可读标成原文可读，不以产品数量计算完成百分比。

## 计划文件和顺序

默认计划：`src/data/mapping-plan.json`。逐家公司维护 `stage`、`done`、`next`；默认顺序为 `order`。

页面中“设为下一家”和上下移会保存到当前浏览器，刷新保留。当前浏览器顺序不会自动写入仓库或跨设备同步。导出计划后可以交给研究任务、写回默认计划文件；导入可恢复导出顺序，新增公司自动追加。

后续执行研究前：先读取本文件与默认计划，若用户指定使用网页调整后的顺序，读取本地页面当前保存的顺序或用户导出的计划，再按该顺序执行。每批更新公司档案与此计划的已做/下一步，不因阶段标签宣称全量完成。

本页面独立于内部知识库，研究内容与订单式优先顺序分开；未知事实仍回到原公司页的检索记录核查。
